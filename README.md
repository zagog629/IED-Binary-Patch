# Immersive-Equipment-Displays-Skyrim-1.7.104-binary-patch
An unofficial binary patch that ports the SKSE plugin Immersive Equipment Displays (IED) 1.7.4 to Skyrim Anniversary Edition 1.7.104 (also valid for 1.7.99). The plugin's author hasn't released an update since 2023. This project patches the shipped x64 DLL directly.
